# OpenPak PS3 name rewrite list.
#
# One entry per line: <match> TAB <replace>. The plugin finds <match> in the vsh process
# memory and overwrites it with <replace>, byte for byte, so <replace> MUST have the same
# length as <match> (tools/stage.sh refuses anything else). Every PSN host name the firmware
# builds ends in one of these suffixes; "playstation.net" and "playstation.org" are 15
# characters, as is "ps3.openpak.org", so the rewrite is a pure suffix swap:
#
#   auth.api.np.ac.playstation.net  ->  auth.api.np.ac.ps3.openpak.org
#
# *.ps3.openpak.org is covered by the public wildcard DNS record and by np-account's per-SNI
# leaf certificates, so no console DNS setting is involved.
#
# This is the same shape as one entry of the network's single signed redirect list (card #128):
# a match, a replacement, nothing console-specific. Entries for other consoles never match
# anything in a PS3, so a later list can be merged in unfiltered: tools/stage.sh appends the
# file named by NAMES_EXTRA (same format) at build time.
#
# Left out on purpose: XML namespace URIs ("http://playstation.net/np/rt/..." are compared
# against what the server sends, not connected to) and JID formats ("%s@%s.%s.%s.playstation.net").
#
# (no header row: the first column is the match, the second the replacement)
